Politique de confidentialité

Cette politique décrit comment Super U / Marché Doré traite les données personnelles dans les applications Marché Doré (clients) et CourseGo (staff).

Données collectées

  • Compte : nom, e-mail, téléphone, mot de passe (hashé).
  • Commandes et livraison : adresses, panier, historique.
  • Localisation : pendant le suivi / les livraisons (CourseGo et client en suivi).
  • Caméra / micro / photos : scan, avis, appels dans l’app (avec permission).
  • Notifications push : jeton d’appareil (Expo / FCM / APNs) pour les alertes.

Finalités

Exécution des commandes, messagerie et appels avec le coursier, alertes opérationnelles, support.

Conservation et sécurité

Les données sont stockées sur nos serveurs. Les mots de passe sont hashés. Les jetons push peuvent être invalidés à la déconnexion ou au refus des notifications.

Vos droits

Contactez support@marchedore.bj pour accès, rectification ou suppression de compte.
